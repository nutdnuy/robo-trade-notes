Date: 2026-09-24. Scope: newly written presentation copy only. Canonical lesson
instructions are unchanged. Review requested by Nuth using the no-ai-slop skill.
This record identifies wording patterns; it does not infer who wrote a text.

The voice to preserve is a slightly eccentric fantasy workshop: Deltaris makers,
brass machines, a walking kettle and occasional engineering jokes. Repeating
short slogans across every section weakens that voice.

| Pattern | Quoted copy | Suggested fix |
| --- | --- | --- |
| Dramatic fragmentation; repeated slogan rhythm | “Great minds. Ridiculous machines.” | Name Deltaris and the workshop directly. |
| Robotic rhythm | “Write a rule. Test it. Find the bug. Repeat.” | Describe what the guide teaches in one sentence. |
| Binary contrast | “บางเมืองสร้างปราสาท” followed by “ชาว Deltaris สร้างเครื่องจักร…” | Start with the Deltaris makers. |
| Dramatic fragmentation | “Six cities. Many questionable ideas.” | Use a plain map heading. |
| Portability failure; binary contrast | “Less guessing. More reading.” | Name the account and API preparation task. |
| Unneeded rhetorical setup | “หุ่นพร้อมแล้ว คนสร้างพร้อมหรือยัง?” | Tell readers where the setup guide starts. |

Keep the specific guild CSV notice and automaton dialogue: these are fictional
character jokes requested for the site, rather than claims or explanations.
Avoid adding more punchlines to navigation and learning instructions. The
chapter title and lead should stay explicit about Python and Webull OpenAPI.
