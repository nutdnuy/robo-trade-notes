# Beta, CAPM และ Factor Exposure

screener ในบทที่ 6 ชนะ benchmark แบบน้ำหนักเท่ากัน คำถามต่อมาคือชนะเพราะอะไร หุ้นที่เลือกอาจเป็นหุ้นที่ขยับแรงกว่าตลาด ในตลาดขาขึ้นจึงขึ้นมากกว่า หรืออาจเอนไปทางหุ้นเล็กหรือหุ้นที่กำลังขึ้น ซึ่งเป็นผลตอบแทนที่หาได้ถูกกว่าด้วยกองทุนดัชนีหรือกองทุน factor

บทนี้แยกผลตอบแทนเป็นส่วนที่มาจากตลาด ส่วนที่มาจาก factor และส่วนที่เหลือ หลังจบบท ผู้เรียนจะประมาณ beta และ alpha ด้วย regression อ่าน standard error ได้ ลบ risk-free rate ถูกความถี่ และรู้ว่า beta ที่ประมาณจากอดีตใช้ hedge อนาคตได้แค่ไหน

## Beta คืออะไร {#beta-intuition}

ถ้าตลาดขึ้น 1% แล้วหุ้นมักขึ้นประมาณ 1.3% หุ้นตัวนี้มี beta ประมาณ 1.3 beta วัดว่าผลตอบแทนของหุ้นขยับตามตลาดมากแค่ไหน ไม่ได้วัดว่าหุ้นดีหรือไม่ดี

$$
\beta = \frac{\operatorname{cov}(r_i, r_m)}{\operatorname{var}(r_m)}
$$

[บทที่ 1](#/chapter-12) แยก alpha กับ beta ไว้แล้วในเชิงความคิด บทนี้วัดออกมาเป็นตัวเลข CAPM (Capital Asset Pricing Model) เขียนผลตอบแทนส่วนเกินของหุ้นเป็นเส้นตรงของผลตอบแทนส่วนเกินของตลาด

$$
r_{i,t} - r_{f,t} = \alpha_i + \beta_i \,(r_{m,t} - r_{f,t}) + \varepsilon_{i,t}
$$

$r_f$ คือ risk-free rate ส่วน $\alpha$ คือผลตอบแทนเฉลี่ยที่อธิบายด้วยตลาดไม่ได้ ถ้าโมเดลถูก $\alpha$ ควรเป็นศูนย์ alpha ที่เป็นบวกจึงเป็นสิ่งที่ผู้จัดการกองทุนอยากแสดง และเป็นตัวเลขที่ต้องตรวจละเอียดที่สุด

> เรื่องเล่าจากโลกสมมติ Quantara · ตลาดลมแห่ง Deltaris
>
> ### เรือที่แล่นเร็วกว่าเพื่อน
>
> กัปตันคนหนึ่งคุยว่าเรือของเขาถึงท่าเร็วกว่าลำอื่นทุกเที่ยวในเดือนนี้ ช่างจดเวลาของทุกลำ แล้วจดความแรงของลมทุกวันไว้ข้าง ๆ
>

## ประมาณ beta ด้วย regression {#estimate-beta}

Notebook สร้างข้อมูลสมมติสามปีที่รู้ค่าจริง หุ้น A มี beta จริง 1.3 และ alpha จริงเป็นศูนย์ เราประมาณด้วยสองวิธี คือ cov/var และ OLS ที่มี intercept ทั้งสองวิธีต้องได้ค่าเดียวกันถึงทศนิยมหลักที่เก้า ถ้าโค้ดสองแบบให้ค่าต่างกัน อย่างใดอย่างหนึ่งผิด

| | ค่าประมาณ | standard error | ค่าจริง |
| --- | --- | --- | --- |
| beta | 1.298 | 0.041 | 1.3 |
| alpha ต่อปี | +4.14% | 11.10% | 0% |
| R² | 0.58 | | |

beta ประมาณได้แม่น แต่ alpha ไม่แม่นเลย alpha ที่ประมาณได้ 4.14% ต่อปีดูน่าสนใจ ทั้งที่ค่าจริงเป็นศูนย์ และ standard error 11.10% แปลว่าช่วงความเชื่อมั่นราว ±22% ครอบศูนย์อยู่สบาย ๆ ข้อมูลรายวันสามปีพอสำหรับวัด beta แต่ไม่พอสำหรับพิสูจน์ alpha ขนาดไม่กี่เปอร์เซ็นต์ต่อปี

alpha รายวันคูณ 252 เป็นรายปีแบบเลขคณิต ตัวเลขนี้ไม่ใช่ CAGR ต้องระบุ convention ทุกครั้งที่รายงาน

## Risk-free rate ต้องตรงความถี่ {#risk-free}

ผลตอบแทนรายวันต้องลบ risk-free rate รายวัน ถ้าอัตรารายปีเป็น 4.5% แบบทบต้น อัตรารายวันคือ $(1.045)^{1/252} - 1 \approx 0.0175\%$

| วิธีลบ | alpha ต่อปีของหุ้น A |
| --- | --- |
| อัตรารายวัน $(1.045)^{1/252}-1$ | +4.14% |
| ลบ 4.5% ทั้งก้อนจากทุกวัน | −1,125% |
| ลบ 4.5%/365 | +5.43% |

แบบที่สองผิดจนมองเห็นทันที แบบที่สามอันตรายกว่า เพราะตัวเลขดูปกติ แต่ alpha สูงเกินไป 1.30 จุดเปอร์เซ็นต์ต่อปี ส่วนต่างนี้มาจากการหาร 365 วันปฏิทินแต่คูณกลับด้วย 252 วันทำการ เป็นข้อผิดพลาดที่ AI สร้างได้ง่ายเมื่อเราไม่บอก convention ใน prompt

อัตราดอกเบี้ยจริงของสหรัฐที่ใช้บ่อยคือผลตอบแทนพันธบัตรรัฐบาลระยะสั้น (T-bill) ข้อมูล factor ของ Kenneth French มีคอลัมน์ RF ที่แปลงเป็นรายวันไว้แล้ว เมื่อใช้ข้อมูลชุดนั้นให้ใช้คอลัมน์นี้ตรง ๆ

## Beta เปลี่ยนตามเวลา {#rolling-beta}

beta ที่ประมาณได้เป็นค่าเฉลี่ยของช่วงที่ใช้ ถ้าหน้าต่างสั้น ค่าจะแกว่งจากความบังเอิญ ถ้าบริษัทเปลี่ยนธุรกิจหรือใช้หนี้มากขึ้น beta จริงก็เปลี่ยน

หุ้น A มี beta จริง 1.30 ตลอดสามปี แต่ beta ที่ประมาณจากหน้าต่าง 60 วันอยู่ระหว่าง 0.92 ถึง 1.69 ความแกว่งทั้งหมดนี้มาจากสัญญาณรบกวน หุ้น C เปลี่ยน beta จริงจาก 0.7 เป็น 1.4 กลางช่วง

| ช่วงข้อมูลของหุ้น C | beta ที่ประมาณได้ |
| --- | --- |
| ครึ่งแรก | 0.64 |
| ครึ่งหลัง | 1.33 |
| ทั้งช่วง | 0.96 |

ค่า 0.96 จากทั้งช่วงไม่ตรงกับช่วงไหนเลย การเลือกความยาวหน้าต่างจึงเป็นการแลกกันระหว่างความแม่นกับความทันสมัย และต้องระบุไว้ใน Spec Card

## Factor exposure {#factors}

CAPM ใช้ตลาดเป็นตัวอธิบายตัวเดียว Fama และ French เพิ่ม factor ขนาดบริษัท (size) และมูลค่า (value) ต่อมา Carhart เพิ่ม momentum factor แต่ละตัวเป็นผลตอบแทนของพอร์ตที่ซื้อหุ้นกลุ่มหนึ่งและขายอีกกลุ่ม เช่น size factor ซื้อหุ้นเล็กและขายหุ้นใหญ่

$$
r_{i,t} - r_{f,t} = \alpha_i + \beta_i\,\text{MKT}_t + s_i\,\text{SIZE}_t + m_i\,\text{MOM}_t + \varepsilon_{i,t}
$$

หุ้น B ใน Notebook ไม่มี alpha จริง แต่มี exposure ต่อ size 0.9 และต่อ momentum 0.7 ในข้อมูลสมมติชุดนี้ทั้งสอง factor มีผลตอบแทนเฉลี่ยเป็นบวก

| โมเดล | alpha ต่อปี | t-stat ของ alpha | R² |
| --- | --- | --- | --- |
| CAPM | +7.76% | 0.81 | 0.38 |
| ตลาด + size + momentum | +1.65% | 0.21 | 0.58 |

CAPM เห็น alpha เกือบ 8% ต่อปี พอเพิ่ม factor ส่วนนี้ส่วนใหญ่กลายเป็นผลตอบแทนจาก factor exposure ที่ประมาณได้ใกล้ค่าจริง คือ beta 0.77, size 0.89 และ momentum 0.71

ข้อนี้ใช้กับ screener ของบทที่ 6 โดยตรง พอร์ต momentum ย่อมมี exposure ต่อ momentum factor ถ้าหลังหัก factor แล้ว alpha เหลือศูนย์ screener ของเราก็ทำซ้ำ factor ที่มีอยู่แล้ว ข้อนี้ไม่ได้แปลว่าไร้ประโยชน์ แต่ต้องเทียบกับต้นทุนของการซื้อ factor นั้นแบบสำเร็จรูป

## Beta hedge ใช้ beta จากอดีต {#beta-hedge}

ถ้าเราอยากได้ผลตอบแทนของหุ้นโดยไม่รับความเสี่ยงตลาด เราขาย index future หรือ ETF ในขนาด beta เท่าของมูลค่าหุ้น ผลตอบแทนที่ hedge แล้วคือ $r_i - \hat\beta\, r_m$

$\hat\beta$ ต้องประมาณจากข้อมูลก่อนวันที่ hedge การใช้ beta จากข้อมูลทั้งช่วงทำให้ hedge ดูสมบูรณ์เกินจริง เพราะใช้ข้อมูลอนาคต Notebook ประมาณ beta ของหุ้น C จากปีแรกได้ 0.65 แล้วใช้ hedge ในสองปีถัดมา

| ช่วงหลัง hedge | beta ที่เหลืออยู่ |
| --- | --- |
| ก่อน beta จริงเปลี่ยน | −0.06 |
| หลัง beta จริงเปลี่ยน | +0.68 |

ก่อน beta เปลี่ยน hedge ทำงานดี หลังจากนั้นพอร์ตที่คิดว่าเป็นกลางต่อตลาดกลับรับความเสี่ยงตลาดเกือบเท่าหุ้นที่ beta 0.7 ทั้งตัว เราจึงต้องประมาณ beta ใหม่เป็นระยะและติดตาม beta ที่เหลือ ซึ่งเป็นหัวข้อของบทที่ 8

## ใช้ข้อมูล factor จริง {#real-factors}

Kenneth French เผยแพร่ข้อมูล factor ของตลาดหุ้นสหรัฐให้ดาวน์โหลดฟรี ทั้งรายวันและรายเดือน มีคอลัมน์ Mkt-RF, SMB, HML, RF และไฟล์ momentum แยก ค่าในไฟล์เป็นเปอร์เซ็นต์ ต้องหาร 100 ก่อนใช้ และต้องตรวจวันที่ให้ตรงกับข้อมูลหุ้นตาม[บทที่ 2](#/chapter-18) ไฟล์ถูกปรับปรุงเป็นระยะ ให้บันทึกวันที่ดาวน์โหลดทุกครั้ง
