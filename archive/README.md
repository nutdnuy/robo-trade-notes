# Archived learning edition

Nuth withdrew all lessons from the public website on 2026-09-13. The original ten chapter HTML pages remain intentionally empty, their legacy hash routes render nothing, and their downloads are excluded from the Pages build.

On 2026-09-23, Nuth requested one new illustrated Webull OpenAPI chapter. Welcome and this new chapter (`chapter-11`) are now published. `src/lib/publishing.js` is the shared allowlist for the reader and standalone exporter. This does not reactivate chapters 01–10.

The lesson Markdown in `content/chapters/`, quizzes in `content/quizzes/`, notebooks and Python examples in `public/downloads/`, and teaching components remain source archives, not active website content. Do not republish them without Nuth's request.

`reader-before-reset/` preserves the reader, Welcome text, and settings immediately before this reset. The complete prior implementation is also available at Git commit `01542caaad3c8964d42a3ae8a7d9447f439a58c1`.
